## Technical Decisions

- **★★★ Verification that assumes preconditions (2026-08-28, 4th obs 2026-09-13)**: a harness
  asserting environment state instead of checking it reports success on wrong inputs. Check
  preconditions explicitly, fail loud. Corollary: **re-run the gates on the commit you are actually
  shipping** — 0.28.0's pre-publish gates were invalidated when `74e91d66` landed after the test run.
  → `patterns/build-and-propagate-pattern.md`

- **★★★ Pathspec commits in a shared checkout (2026-08-27, 5th obs 2026-09-13)**: two sessions in one
  checkout poison each other's index — and a bare `update` commit from a parallel session absorbed
  another's in-flight work again. Use `git commit -F - -- <paths>`; a test read from a tree a peer is
  mid-editing is provisional — re-run before reporting red (2026-09-11).
  → `patterns/multi-session-checkout-safety.md`

- **★★ A media property set before `src` is a guess, not config (2026-09-11)**: `playbackRate` written
  before `el.src` was silently reset by the load algorithm's last step — stored, PUT and reported
  correctly, and never once took effect.

## Known Issues — full detail

- **The installed `.app` freezes its dist at build time** (2026-09-08, 5th obs 2026-09-13): later
  commits need a rebuild; a bundle-only bug needs `DREAMCONTEXT_CLI` pinned to the bundle, and no
  upgrade banner appears at the same version. **Suspect a stale app before a broken feature** — a
  three-day "microphone is broken" was a 0.27.0 bundle with no `NSMicrophoneUsageDescription`
  (WKWebView denies `getUserMedia` outright, never prompting). ⌘Q is needed for an `Info.plist` or
  bundle change; for a dist-only change a reload suffices when `resolve_cli()` picks the npm-linked
  global CLI over the bundled one. The Dock may run `/Applications` while `app install` writes
  `~/Applications` — replace both.

- **`gh` account mismatch 403s the push** (2026-09-08, 3rd obs): remote is `meanllbrl/dreamcontext`,
  the active `gh` account is often `mehmet-ouro`, which has no write. `gh auth switch`, push, switch
  back. Unapplied fix: `git config --local credential.username meanllbrl`.

- **Full suite on a saturated machine times out** (2026-07-27, recurring): ~11/135 integration tests
  exceed the 5s limit on CLI spawn alone. Run the suite alone.
