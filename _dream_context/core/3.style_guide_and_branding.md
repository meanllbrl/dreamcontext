## Branding

- **Name**: dreamcontext (lowercase, one word). "Sleepy" names only the Search/Ask surface and the mascot persona — the project, package, CLI and wordmark stay "dreamcontext". No rename.
- **Binary / npm package**: `dreamcontext`. **Primary colour**: violet (`--color-violet-*`).
- **Logo**: violet folded-diamond "dream gem", one SVG (`BrandMark.tsx`) for every brand mark.
- **Palette (owner)**: purple-magenta gradient — `#641787`, `#781ca3`, `#8200a6`, `#db04b4`. **Typeface**: Visby CF. **Grid**: 4px. **Density beats theatricality** — info-dense, searchable, fast, the final report above the fold.
- **"Lab" is "Insights" in the UI**; `lab` never surfaces. Maturity: one ladder, `alpha | beta | off` (`MaturityTag`): `maturity` = offered but unfinished (never disables); `badge` = announced but NOT offered (always `disabled` + muted).
- **Onboarding: one front door** (`setup`); a half-install state is a bug.
- **Wordmark**: two-tone — "dream" neutral/light, "**context**" violet. Never repeat it outside the sidebar lockup.

## Sleepy — Mascot & Surface

- Assistant/mascot persona AND the Search/Ask surface name, deliberately shared with the sleep-debt level of the same name. Voice: grounded, local, no tokens — Sleepy never calls an LLM mid-task.
- **★★★ Two channels, never one (2026-08-28)**: **colour = MOOD, movement = MODE.** Tint carries state (green working, magenta asking, violet ready); chat mode is shape and motion only — Plan writes, Develop forges — so a blocked Develop agent still reads as asking, mid-swing. Never encode mode as a costume or prop. Theme ink only; `--color-warning` is reserved for genuinely hot things; no baked hex. `SleepyMascot.tsx`. A static nav section hue is chrome, not a state (2026-09-22) — see `2.memory.md`.
- **Game grammar, not theatre (2026-09-25, owner)**: agents read as a team: Sleepy face + role emblem on a static maker or judge tint (chrome; never a mood hue, accent or warning). A step's tense is its status; a run is a quest map, a loop-back a round, a finish one calm win beat. Plain words, no jargon, no confetti.

## Dashboard Layout

- **Header, 3 zones**: sidebar-toggle · vault name centred · theme-toggle + avatar. No wordmark or logo; the single brand lockup lives in the sidebar.
- **Sidebar lockup**: BrandMark + two-tone wordmark, once, at the top. Collapsing hides it and moves the toggle to the header's left zone (`useSidebarCollapse.ts`).
- **No page headlines**: no h1, no `.page-title`. The sidebar nav label IS the page title; bodies begin with content. No exceptions for new pages.
- **Sleepy is the default landing page** (first Workspace nav item).
- **A settings row follows its neighbours' grammar**; new or experimental settings go at the BOTTOM of their section, collapsed, behind a maturity tag.
- **Motion (2026-09-25)**: one enter curve `--ease-out`, one loop period `--motion-breath` for a live dot; every animation stands down under `prefers-reduced-motion`. **One filled accent per screen** (the primary action, or a pending question's first choice); a selected chip or tab is a neutral surface.

## CLI Conventions

- **Colours**: green ✓ · red ✗ · cyan ℹ/emphasis · dim secondary · bold headers. **No emoji** — `✓ ✗ ℹ` are symbols; content files carry none.
- **Voice**: terse; errors name what failed; hints `ℹ Next:`; `formatTable()` tables.
- **Files**: kebab-case source; slugified user input for tasks/features/knowledge. **Code**: TypeScript strict, named exports, async/await, ~200-300 lines per file.
