## Branding

- **Name**: dreamcontext (lowercase, one word). "Sleepy" names only the Search/Ask surface and the mascot persona — the project, package, CLI and wordmark stay "dreamcontext". No rename.
- **Binary / npm package**: `dreamcontext`. **Primary colour**: violet (`--color-violet-*`).
- **Logo**: violet folded-diamond "dream gem" (lavender rounded diamond + leaf/eye + right wing + outer ring + glow), one scalable SVG at `dashboard/src/components/brand/BrandMark.tsx` (`useId()` for SSR/de-dup safety), driving the sidebar lockup, constellation centre dot, favicon and macOS app/Dock icon.
- **Wordmark**: two-tone — "dream" neutral/light, "**context**" violet. Never repeat it outside the sidebar lockup.

## Sleepy — Mascot & Surface

- Assistant/mascot persona AND the Search/Ask surface name, deliberately shared with the sleep-debt level of the same name. Voice: grounded, local, no tokens — Sleepy never calls an LLM mid-task. Ask summary: "Grounded · Extractive · No tokens."
- **★★★ Two channels, never one (2026-08-28)**: **colour = MOOD, movement = MODE.** Tint carries state (green working, magenta asking, violet ready); chat mode is shape and motion only — Plan writes, Develop forges — so a blocked Develop agent still reads as asking, mid-swing. Never encode mode as a costume or prop (three wardrobe drafts rejected). Theme ink only; `--color-warning` is reserved for genuinely hot things; no baked hex. `SleepyMascot.tsx`.

## Dashboard Layout

- **Header, 3 zones**: sidebar-toggle · vault name centred · theme-toggle + avatar. No wordmark or logo; the single brand lockup lives in the sidebar.
- **Sidebar lockup**: BrandMark + two-tone wordmark, once, at the top. Collapsing hides it and moves the toggle to the header's left zone (`useSidebarCollapse.ts`).
- **No page headlines**: no h1, no `.page-title`. The sidebar nav label IS the page title; bodies begin with content. No exceptions for new pages.
- **Sleepy is the default landing page** (first Workspace nav item).
- **A settings row follows its neighbours' grammar**: a hotkey field is a readOnly input capturing on focus (Backspace clears, Escape cancels) printing plain labels — `Alt+Space`, `Ctrl+Shift+V`, `F8` — never ⌥⌘ glyphs. New or experimental settings go at the BOTTOM of their section, collapsed, behind a BETA badge.

## CLI Conventions

- **Colours**: green ✓ · red ✗ · cyan ℹ/emphasis · dim secondary · bold headers. **No emoji** — `✓ ✗ ℹ` are symbols; content files carry none.
- **Voice**: terse. `✓ Task created: my-task.md`, never "Successfully completed…". Errors name what failed: `✗ Feature not found: auth`. Hints prefix `ℹ Next: …`. Tables via `formatTable()` (`src/lib/format.ts`) with `─` separators.
- **Files**: kebab-case source; slugified user input for tasks/features/knowledge. **Code**: TypeScript strict, named exports, async/await, ~200-300 lines per file.
