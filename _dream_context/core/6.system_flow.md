# System Flow

## Design Rationale

Two-stage memory selection (Joo & Frank, Science 2025): the hippocampus records experience AND bookmarks salient moments; during sleep those bookmarks compete for transfer to the neocortex. Selection and storage are separate processes — that split is the whole design.

> Brain-mechanism mapping, the bookmark/decay/trigger/distillation data flows and the full path table: `knowledge/archive/6.system_flow-neuroscience-2026-h2.md`.

## Session Lifecycle

- **START** — hook renders the snapshot (soul, person, memory, tasks, objectives, changelog, knowledge index, warm knowledge, bookmarks, triggers) under a demotion ladder targeting 18,000 chars against the harness's 20,000 hard limit.
- **ACTIVE** — agent logs progress (`tasks log`, `core changelog add`), bookmarks (`bookmark add -s 1|2|3`), touches knowledge, queries `memory recall`.
- **END** — hook scores the session (0-10 weighted sum: tokens 4, changes 3, tools 1.5, substance 1.5), links bookmarks, increments debt.
- **CONSOLIDATION** — `sleep start` → parallel `sleep-tasks` + `sleep-state` + `sleep-product` + `sleep-learn` (+ `sleep-migration` only when migrations pend) → `reflect` → roadmap refresh → `sleep done`. `sleep done` never auto-commits `_dream_context/`; the human does.

## Salience & Triggers

★ notable decision/pattern → consolidate if relevant · ★★ architectural decision, preference, significant bug → should · ★★★ critical constraint, breaking change, fundamental choice → must, fires an immediate advisory.

Debt ≥60 `DEBT_MUST_SLEEP` required · ≥40 `DEBT_SLEEPY` recommended · ≥24 `DEBT_DROWSY` offered after the current task · any ★★★ bookmark advises regardless of debt · 5+ sessions advises a rhythm check.

> `scoreSession` is a log-compressed weighted sum over `SESSION_SCORE_MAX = 10`. A cooldown caps consolidation at ~3 cycles/day, overridden at `DEBT_COOLDOWN_OVERRIDE` (2 × must-sleep); deep-sleep authority starts at `DEBT_DEEP_AUTHORITY` = 90. Thresholds are per-brain settings (`sleep: {}` in `.config.json`), not source constants. Canonical: `src/lib/sleep-consolidation.ts`.

## Key Paths & Surfaces

- **State**: `state/.sleep.json` (runtime), `core/0-6.*` (long-term), `people/<slug>.md`, `core/objectives/`, `state/*.md` (tasks).
- **Agent routes** (`src/server/routes/`): `POST /api/agent/download` — the one route writing OUTSIDE the project (to `~/Downloads`, returns the absolute path; desktop-only, extension allowlist, never overwrites, 40MB cap); `POST /api/agent/reveal` (Finder, file selected); `PUT /api/agent/voice/config` (J.A.R.V.I.S hotkey/engine); `/stt` + `/tts` in `agent-voice.ts`. `/api/artifacts` was removed with the saved-blocks layer.
- **Local desktop rollout is five stages**: build → `tauri build` → deep adhoc codesign → `app install --from` → ⌘Q relaunch. A bundle-only bug needs `DREAMCONTEXT_CLI` pinned to the bundle, or the npm link runs the working tree instead.

## Agent & Hook Inventory

Ships SKILL.md, seven hooks (SessionStart, Stop, SubagentStart, PreToolUse, UserPromptSubmit, PostToolUse, PreCompact) and 13 agents in `agents/`: four always-fire sleep specialists (`sleep-tasks`, `sleep-state`, `sleep-product`, `sleep-learn`), two conditional (`sleep-migration`, `sleep-federation`), a three-agent initializer (scout, ingestor, verifier), a three-agent curator (worker, auditor, verifier), and `dreamcontext-explore`. No standalone orchestrator — the main agent fans out per SKILL.md. Installed to `.claude/` by `dreamcontext install-skill`.
