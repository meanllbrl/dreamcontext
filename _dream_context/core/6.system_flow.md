# System Flow: How the Agent Memory System Works

## Design Rationale

Inspired by a 2025 Science paper (Joo & Frank) revealing the brain's two-stage memory selection system. The hippocampus records experiences AND fires "awake ripples" to bookmark important moments during the day. During sleep, bookmarked memories compete for consolidation, with only the strongest patterns winning transfer to the neocortex. Key insight: memory selection (tagging) and memory consolidation (storage) are separate processes.

## Session Lifecycle

**SESSION START** — Hook generates snapshot (soul, person, memory, tasks, objectives, changelog, knowledge index, warm knowledge, bookmarks, triggers). Consolidation directive on debt thresholds: ≥60 required, ≥40 recommended, ≥24 offered.

**ACTIVE WORK** — Agent logs progress (`tasks log`, `core changelog add`), bookmarks (`bookmark add -s 1|2|3`), tracks access (`knowledge touch`), queries (`memory recall`).

**SESSION END** — Hook scores session (0-10 weighted sum: tokens 4, changes 3, tools 1.5, substance 1.5), links bookmarks, increments debt.

**CONSOLIDATION (REM SLEEP)** — Triggered by debt ≥40, critical bookmarks, 12+ sessions, or task completion. Protocol: `sleep start` (epoch + migrations) → read bookmarks/sessions → update core/knowledge → anti-bloat → feature PRDs → `sleep done` (clear epoch state, reset debt).## Neuroscience Mapping

## Salience Levels

| Level | When to Use | Consolidation Effect |
|---|---|---|
| ★ (1) | Notable decision, useful pattern | Consolidate if relevant |
| ★★ (2) | Architectural decision, user preference, significant bug | Should consolidate |
| ★★★ (3) | Critical constraint, breaking change, fundamental design choice | Must consolidate (triggers immediate advisory) |

## Consolidation Triggers

> Rescaled 2026-07-29 when `scoreSession` became a log-compressed weighted sum (novel tokens 4, changes 3, tools 1.5, substance 1.5) over `SESSION_SCORE_MAX = 10`, replacing three saturating 0-3 buckets. A cooldown caps consolidation at ~3 cycles/day, overridden at `DEBT_COOLDOWN_OVERRIDE` (2 × must-sleep); deep-sleep authority starts at `DEBT_DEEP_AUTHORITY` = 90. Canonical constants: `src/lib/sleep-consolidation.ts`.

| Condition | Directive |
|---|---|
| Debt >= 60 (`DEBT_MUST_SLEEP`) | Consolidation required (Must Sleep) |
| Debt >= 40 (`DEBT_SLEEPY`) | Consolidation recommended |
| Debt >= 24 (`DEBT_DROWSY`) | Offer after the current task |
| Critical (★★★) bookmarks exist | Critical bookmark advisory (regardless of debt) |
| 5+ sessions since last sleep | Rhythm check advisory |
