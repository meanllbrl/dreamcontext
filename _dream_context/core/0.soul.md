## Project Identity

dreamcontext is a TypeScript CLI published as an npm package that gives AI coding agents a structured, persistent brain across sessions. It kills the token-burning search spiral by pre-loading context via a SessionStart hook (zero agent tool calls), organising knowledge across purpose-built files, and consolidating in a RemSleep cycle that mirrors how the brain processes memory during sleep. Claude Code only; Codex CLI deprecated. Agent and hook inventory: `6.system_flow.md`.

## Core Principles

- **Context cheap to load**: `snapshot` fast, compact, high-signal.
- **CLI > agent editing**: structural ops via CLI; native tools for direct edits.
- **LIFO everywhere**: changelogs, memory, constraints — newest at top.
- **4,000 chars per core file, 20,000 per snapshot** (the harness's hard limit). Over means extract; archives stay findable via recall.
- **No placeholders** — an empty file is worse than no file.
- **"Learning to act" is positioning**, a direction, not a shipped capability. Restored 2026-09-21: an anti-bloat trim dropped this line, and `positioning-doc.test.ts` exists to catch exactly that — the bullet is what keeps the roadmap from being described as something that already ships.

## Constraints

- **★★★ The git remote is named `main`, not `origin` (re-verified 2026-09-13)**: push `git push main main`. The name has flipped twice — always `git remote -v` first, never trust either name or a prior note.

## Agent Behaviours & Rules

- **★★★ Sub-agents run on OPUS, never Fable** (owner, 2026-08-23; restated 2026-09-11): every Agent-tool dispatch and every `claude -p` builder passes `--model opus` / `model: opus` explicitly. Fable is the main loop only; an omitted model silently inherits it.
- **HARD RULE — docs in lockstep**: every change updates skill + references, agents/packs, and README + DEEP-DIVE. A feature without docs is incomplete.
- **Every commit must typecheck standing alone** (2026-09-08, 2nd obs) — `git archive` + root and dashboard `tsc`.
- Run `npm test` before calling work complete (integration needs `npm run build`), and keep the WHOLE output — a tail loses a failure's identity.
- **Strict TypeScript**: no implicit any, no unused locals. Conventional commits + Co-Authored-By.
- **Skill triage before action** (SKILL.md rule #2), and never claim a capability is missing without checking the skill references first.
