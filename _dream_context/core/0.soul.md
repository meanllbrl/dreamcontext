## Project Identity

dreamcontext is a TypeScript CLI published as an npm package that gives AI coding agents a structured, persistent brain across sessions. It kills the token-burning search spiral by pre-loading context via a SessionStart hook (zero agent tool calls), organising knowledge across purpose-built files, and consolidating in a RemSleep cycle that mirrors how the brain processes memory during sleep. Claude Code only; Codex CLI deprecated. Agent and hook inventory: `6.system_flow.md`.

## Core Principles

- **Context cheap to load**: `snapshot` fast, compact, high-signal.
- **CLI > agent editing**: structural ops via CLI; native tools for direct edits.
- **LIFO everywhere**: changelogs, memory, constraints — newest at top.
- **4,000 chars per core file, 20,000 per snapshot** (the harness's hard limit). Over means extract; archives stay findable via recall.
- **No placeholders** — an empty file is worse than no file.
- **"Learning to act" is positioning**, a direction, not a shipped capability.

## Constraints

- **★★★ The git remote is `origin` (re-verified 2026-09-10)**: push `git push origin main`. It was once named `main`; that constraint is retired. Re-check with `git remote -v` rather than trusting either name.
- **Node >= 18, ESM-only**: `"type": "module"`, native `node:*`, `.js` imports even from TS.
- **Runtime deps are never bundled** (tsup externalises them); templates ride via `onSuccess` into `dist/templates`.
- **Dashboard deps isolated**: React/Vite live in `dashboard/package.json`, never the CLI's.
- **Visby CF is commercial** — falls back to system, never ships in the tarball.

## Agent Behaviours & Rules

- **HARD RULE — docs in lockstep**: every change updates skill + references, agents/packs, and README + DEEP-DIVE. A feature without docs is incomplete.
- **Every commit must typecheck standing alone** (2026-09-08, 2nd obs) — verified by `git archive` plus root and dashboard `tsc`. Reorder rather than ship one that only compiles beside its successor.
- Run `npm test` before calling work complete (integration needs `npm run build`).
- **Strict TypeScript**: no implicit any, no unused locals. Conventional commits + Co-Authored-By.
- **Skill triage before action** (SKILL.md rule #2) — skipping the skill load is a regression.
- **Bookmarks are the primary consolidation signal**; ★★★ outrank raw change counts.

## Warnings

- Never bundle runtime deps; never pass `--no-verify`; never skip pre-commit hooks.
- Never give `snapshot` chalk or interactive prompts — a shell hook consumes it.
- Never change `insertToJsonArray` from its `'top'` default (LIFO).
- Don't add `.claude/` to this repo's own context; skill and agents ship from `skill/` and `agents/`.
- Multi-session checkout: `knowledge/patterns/multi-session-checkout-safety.md` (4th obs).
