## Project Identity

dreamcontext is a TypeScript CLI tool published as an npm package that gives AI coding agents a structured, persistent brain across sessions. It eliminates the token-burning search spiral by pre-loading structured context via a SessionStart hook (zero agent tool calls), organizing knowledge across purpose-built files (soul/user/memory/knowledge/state), and consolidating during a RemSleep cycle that mirrors how the brain processes memory during sleep.

Ships with SKILL.md + seven agents: initializer, explore, three sleep specialists (sleep-tasks, sleep-state, sleep-product) + two conditional (sleep-migration, sleep-federation). No standalone orchestrator — main agent fans out per SKILL.md. Agent files live in `agents/` and install to `.claude/` via `dreamcontext install-skill`. Seven hooks: SessionStart, Stop, SubagentStart, PreToolUse, UserPromptSubmit, PostToolUse, PreCompact. Supports Claude Code only; Codex CLI deprecated.

## Core Principles

- **Context cheap to load**: `snapshot` must be fast, compact, high-signal. No bloat.
- **CLI > agent editing**: Structural ops (create/insert/search) via CLI; native tools for direct edits.
- **LIFO everywhere**: Changelogs, memory, constraints — newest at top.
- **4,000-char ceiling per core file**: Extract to knowledge when over; archived content stays findable via recall.
- **No placeholders**: Empty files worse than no files. Template "(Add X here)" is failure.
- **Positioning uses "learning to act" framing**: Not a shipped capability; signals direction.

## Constraints

- **★★★ Git remote is `main` (2026-07-28)**: This repo's remote is `main` (verified `git remote -v`), NOT `origin`. Push: `git push main main`. When reviewing branches use base SHA not branch name `main` to avoid ambiguous-ref warnings (`refs/heads/main` AND `refs/remotes/main/main` both exist).
- **Node >= 18 (ESM-only)**: `"type": "module"`, native `node:fs`/`node:path`, `.js` import extensions even for TS.
- **External deps not bundled**: tsup externalizes all runtime deps; they install via node_modules.
- **Templates ship with dist**: tsup `onSuccess` copies `src/templates` to `dist/templates`.
- **Dashboard deps isolated**: `dashboard/package.json` is separate; React/Vite NOT in CLI package.json.
- **Visby CF font commercial**: Dashboard brand font; CSS falls back to system; don't embed in npm.

## Agent Behaviors & Rules

- **HARD RULE — docs in lockstep (2026-06-25)**: Every dreamcontext change MUST update (1) skill + references, (2) agents/packs, (3) README + DEEP-DIVE. Feature without docs is incomplete.
- Always run `npm test` before complete. Unit (`tests/unit/`) + integration (`tests/integration/`, requires `npm run build`).
- Template tokens: `{{PROJECT_NAME}}`, `{{DATE}}`, etc. When changing templates, update `init.ts` accordingly.
- Memory recall: BM25F + Haiku rerank; rankScore derived, hit.score flat BM25 so thresholds unchanged.
- **SKILL.md rule #2 "Skill triage before action"**: Lists 9 task→skill matches. Skipping skill load is regression.
- **Bookmarks primary consolidation signal**: ★★★ take priority over raw change counts.

## Warnings

- Never bundle runtime deps. tsup externalizes deliberately.
- Never add `--no-verify` or skip pre-commit hooks.
- Never make `snapshot` use chalk/interactive prompts (consumed by shell hook).
- Never change `insertToJsonArray` default from `'top'` (LIFO).
- Don't add `.claude/` to this repo's own context. Skill/agents in `skill/` + `agents/` for distribution.
