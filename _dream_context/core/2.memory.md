- **★★★ Verification that assumes preconditions (2026-08-28, 3rd obs)**: a harness that asserts environment state as fact instead of checking it reports success on wrong inputs — build-and-propagate assumed "the global CLI is npm-linked" and shipped published docs over new ones, green throughout. Check preconditions explicitly, fail loud. → `knowledge/patterns/build-and-propagate-pattern.md`

- **★★★ Pathspec commits in a shared checkout (2026-08-27)**: two agent sessions in one checkout corrupt each other's commits, because B's `git add` replaces the index between A's add and commit. `git commit -F - -- <paths>` takes working-tree content for those paths and cannot be poisoned by another process's index. Verify from `git archive HEAD` into a temp dir with BOTH root and `dashboard/node_modules` symlinked. → `knowledge/patterns/multi-session-checkout-safety.md`

- **★★ Validate the measuring instrument before trusting its verdict (2026-09-05)**: an instrument's own limits arrive disguised as the subject's faults — OpenUI Wave 6's three "failures" were all harness bugs against a model that scored 6/6. Verify the harness before trusting a verdict that contradicts a manual spot-check. → `knowledge/patterns/runtime-measurement-verification.md`

- **★★ The parent is the wire (2026-09-06)**: when a remote cannot express your model, map onto what it HAS and carry the extra bit in a channel it tolerates, rather than asking the remote to grow. Declared task statuses live under a shipped parent; the remote sees the parent, the child rides as a `dc:<key>` label/tag. → `knowledge/patterns/parent-on-the-wire-child-in-a-sidecar.md`

## Known Issues

- **Full suite on a saturated machine times out (2026-07-27, recurring)**: under high CPU load `npm test` fails ~11/135 integration tests at the 5s limit — they spawn the CLI and the spawn alone exceeds the window. Run the suite alone.

- **`releases add --yes` over-sweeps (2026-07-07, recurring)**: auto-discovery can sweep far more tasks/changelog/features than belong (v0.13.1 swept 105 tasks for a 2-feature patch). Trim after each add. Did NOT reproduce on 0.28.0 (2026-09-10, swept 0) — watch once more before retiring this.
