## Known Issues

- **Full suite on saturated machine times out 11 tests (2026-07-27, recurring)**: `npm test` on high CPU load fails 11/135 integration tests at 5s limit. Tests spawn CLI; spawn itself can exceed window. Workaround: run suite alone or on lightly-loaded machine.

- **RELEASES.json indent drift → 1000s-line diffs (2026-07-25, ★★ recurring)**: Tool rewrites with 1-space instead of CLI's 2-space → 6,700-line diff for 3-line change. CLI uses 2 spaces; match it or diff bloats. Never hand-write/reformat with non-CLI tooling.

- **`releases add --yes` over-sweeps (2026-07-07, recurring)**: Auto-discovery sweeps far more tasks/changelog/features than belong. v0.13.1 swept 105 tasks for a 2-feature patch. Manual trim after each add. Avoid `--yes` or correct afterward.
