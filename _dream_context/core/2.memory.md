## Technical Decisions

> Conclusions only; the worked detail is in the linked pattern. Archived sets (via `memory recall`): `2.memory-2026-h2.md`, `2.memory-2026-08{,-b}.md`, `2.memory-2026-09.md` (the last now also holds the 2026-09-05/06/10 ★★ pointers archived on 2026-09-13).

- **★★★ Every path that reads vault markdown must contain its symlinks (2026-09-11, reproduced end-to-end)**: a `knowledge/patterns/x.md → lab/credentials.json` symlink planted in a fake vault made the prompt hook print an API key into agent context — arbitrary local-file exfiltration, and a shared brain repo is exactly where a hostile link would arrive. `lstat` the leaf to reject the link itself AND `realpath`-contain it under its directory. The lesson generalizes to EVERY new vault-reading path, not just patterns. → `src/lib/patterns.ts`
- **★★★ Sleep no longer folds user corrections into pattern content (2026-09-10, owner decision)**: when a user contradicts/narrows/extends an injected pattern, the AWAKE agent updates that pattern file before finishing the task — the hook says so on every injection. Sleep keeps create-from-recurrence/condense/retire and reports a contradicted-but-unupdated pattern as a missed awake rule, never rewrites it itself. Rationale: by the time a cycle runs, the argument that produced the correction is gone and only its conclusion survives. → `patterns/hook-delivered-must-not-miss-rules.md`
- **★★★ Verification that assumes preconditions (2026-08-28, 4th obs 2026-09-13)**: a harness asserting environment state instead of checking it reports success on wrong inputs. Check preconditions explicitly, fail loud. Corollary: **re-run the gates on the commit you are actually shipping** — 0.28.0's pre-publish gates were invalidated when `74e91d66` landed after the test run. → `patterns/build-and-propagate-pattern.md`
- **★★★ Pathspec commits in a shared checkout (2026-08-27, 5th obs 2026-09-13)**: two sessions in one checkout poison each other's index — and a bare `update` commit from a parallel session absorbed another's in-flight work again. Use `git commit -F - -- <paths>`. → `patterns/multi-session-checkout-safety.md`

## Known Issues

- **Full suite on a saturated machine times out** (2026-07-27, recurring): ~11/135 integration tests exceed the 5s limit on CLI spawn alone. Run the suite alone.
- **`releases add --yes` over-sweeps** (2026-07-07, recurring): trim after each add. Did NOT reproduce on 0.28.0 (2026-09-10) — one more clean cycle and retire this.
- **`gh` account mismatch 403s the push** (2026-09-08, 3rd obs): remote is `meanllbrl/dreamcontext`, active `gh` account is often `mehmet-ouro` (no write). `gh auth switch`, push, switch back. Unapplied fix: `git config --local credential.username meanllbrl`.
- **The installed `.app` freezes its dist at build time** (2026-09-08, 5th obs 2026-09-13): later commits need a rebuild; a bundle-only bug needs `DREAMCONTEXT_CLI` pinned to the bundle, and no upgrade banner appears at the same version. **Suspect a stale app before a broken feature** — a 3-day "microphone is broken" was a 0.27.0 bundle with no `NSMicrophoneUsageDescription` (WKWebView denies `getUserMedia` outright, never prompting). ⌘Q is needed for an `Info.plist`/bundle change; for a dist-only change a reload suffices when `resolve_cli()` picks the npm-linked global CLI over the bundled one. The Dock may run `/Applications` while `app install` writes `~/Applications` — replace both.
