- **★★ Sub-agents run on OPUS, never Fable (2026-08-23, owner directive)**: every dispatched sub-agent — Agent-tool judges/explorers AND CLI builder sessions (`claude -p --model …`) in goal-skill/curator/council flows — runs `--model opus`, never the orchestrator's own Fable model. Fable is the main-loop model only; it does not inherit downward. Pass the model explicitly on every dispatch — an omitted model silently inherits the parent.

Traps: the `five_hour`/`seven_day` summaries hold their number under `utilization`, only `limits[]` uses `percent`, and `limits[]` nests INSIDE `utilization`. That file also holds `oauthAccount`/`accountUuid`/spend, so the wire shape is built field-by-field, never spread. Source: file:src/lib/claude-usage.ts.

## Known Issues


- **Full suite on a saturated machine times out (2026-07-27, recurring)**: under high CPU load `npm test` fails ~11/135 integration tests at the 5s limit — they spawn the CLI and the spawn alone exceeds the window. Run the suite alone.

- **RELEASES.json indent drift → 1000s-line diffs (2026-07-25, ★★ recurring)**: a 1-space rewrite instead of the CLI's 2-space turned a 3-line change into a 6,700-line diff. Match 2-space; never reformat with other tooling.

- **`releases add --yes` over-sweeps (2026-07-07, recurring)**: auto-discovery sweeps far more tasks/changelog/features than belong — v0.13.1 swept 105 tasks for a 2-feature patch. Avoid `--yes`, or trim manually after each add.
