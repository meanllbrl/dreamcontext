> Conclusions only; worked detail is in the linked pattern. Archived sets (via `memory recall`): `2.memory-2026-h2.md`, `2.memory-2026-08{,-b}.md`, `2.memory-2026-09{,-b}.md` — the `-b` set holds the 2026-08-27/28 and 2026-09-11 decisions archived on 2026-09-21.

- **★★★ Colour=MOOD reconciled: a nav section hue is chrome, not a state** (2026-09-22, plan D4) — `orthogonal-encoding-channels.md` governs a small element carrying N independent STATES; a group hue never changes at runtime and carries no news, so it is static identity like the icon's drawing. Compliant iff it never occupies accent or warning, always loses to active/unread, and renders as a tinted surface (10/22/55 mix) never a filled swatch. `--nav-hue` defaults to today's grey so the mapping is total.
- **`.svg` is never served, and the media CSP is image-only** (2026-09-22) — `/api/graph/content` is generic: `PdfViewer` iframes its URL same-origin with no `sandbox`, which is safe for a PDF and false for a script-bearing SVG. Keeping `.svg` out of the allowlist (it falls through to the text branch) removes the class at no cost; agents attach raster screenshots and plots.
- **A builder CLI session resumes under any account with capacity** (2026-09-22, used 3x this run) — `~/.claude/projects` is shared by all account sandboxes, so a session hitting a usage limit is resumed by pointing `CLAUDE_CONFIG_DIR` at an account that still has capacity. No re-plan, no lost context.
- **★★★ Symlink containment on every vault-reading path** (2026-09-11, reproduced end-to-end) — the rule and its rationale are in `0.soul.md` Warnings; implementation `src/lib/patterns.ts`, detail `2.memory-2026-09-b.md`.
- **★★★ Sleep no longer folds user corrections into pattern content (2026-09-10, owner decision)**: when a user contradicts, narrows or extends an injected pattern, the AWAKE agent updates that pattern file before finishing the task. Sleep keeps create-from-recurrence, condense and retire, and reports a contradicted-but-unupdated pattern as a missed awake rule — by the time a cycle runs, the argument that produced the correction is gone. → `patterns/hook-delivered-must-not-miss-rules.md`
- **★★★ Check preconditions, and re-run the gates on the commit you actually ship** (2026-08-28, 4th obs) → `patterns/build-and-propagate-pattern.md`, archive `2.memory-2026-09-b.md`.
