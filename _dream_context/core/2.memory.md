## Technical Decisions

> Conclusions only; the worked detail is in the linked pattern. Archived sets (via `memory recall`): `2.memory-2026-h2.md`, `2.memory-2026-08.md`, `2.memory-2026-08-b.md`, `2.memory-2026-09.md`.

- **★★★ Sleep no longer folds user corrections into pattern content (2026-09-10, owner decision)**: when a user contradicts/narrows/extends an injected pattern, the AWAKE agent updates that pattern file before finishing the task — the hook says so on every injection. Sleep keeps create-from-recurrence/condense/retire and reports a contradicted-but-unupdated pattern as a missed awake rule, never rewrites it itself. Rationale: by the time a cycle runs, the argument that produced the correction is gone and only its conclusion survives. → `patterns/hook-delivered-must-not-miss-rules.md`
- **★★ Rarity in a small filename corpus is not evidence of specificity (2026-09-10)**: the first shipped pattern-trigger gate fired three patterns off a routine status message because "test"/"code"/"file" were each unique among 42 filenames. Fix was to scale required evidence to prompt length, not to add a stopword list — a 3-word message IS its whole subject; a word inside a 400-word doc is coincidence. → `patterns/hook-delivered-must-not-miss-rules.md`
- **★★★ Verification that assumes preconditions (2026-08-28, 3rd obs)**: a harness asserting environment state instead of checking it reports success on wrong inputs. Check preconditions explicitly, fail loud. → `patterns/build-and-propagate-pattern.md`
- **★★★ Pathspec commits in a shared checkout (2026-08-27)**: two sessions in one checkout poison each other's index. Use `git commit -F - -- <paths>`. → `patterns/multi-session-checkout-safety.md`
- **★★ Validate the instrument before its verdict (2026-09-05)**: a harness's own limits arrive disguised as the subject's faults. → `patterns/runtime-measurement-verification.md`
- **★★ The parent is the wire (2026-09-06)**: when a remote can't express your model, map onto what it HAS and carry the extra bit in a channel it tolerates. → `patterns/parent-on-the-wire-child-in-a-sidecar.md`
