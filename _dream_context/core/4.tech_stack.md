## Tech Stack

TypeScript 5.7, Node.js >= 18, ESM-only npm package: a single-binary CLI that also serves a local web dashboard, plus the Lab analytics-insights subsystem (v0.10.7+). No external services for core operation — all state lives on the local filesystem under `_dream_context/` inside the user's project.

> Full source layout, build pipeline and infrastructure: `knowledge/archive/4.tech_stack-dependencies-2026-h2.md`.

## Runtime-installed & optional dependencies

- **node-pty** (in-app terminal) is native and cannot be bundled, so it installs at RUNTIME into `~/.dreamcontext/native` — a dir carrying its own minimal manifest so npm treats it as a project rather than walking up and adopting `$HOME`. Resolution tries the CLI package root first (npm install / dev link), the native dir second. Deliberately NOT a package.json dependency, and nothing may be installed into the code-signed `.app`.
- **Dashboard fonts**: 0.27.0 added three `@fontsource-variable/*` imports under `dashboard/`. A root `npm install` does NOT cover them — run `npm install` inside `dashboard/` or `npm run build` fails.
- **Voice (J.A.R.V.I.S)** runs on one OpenRouter key at `~/.dreamcontext/voice.json` (mode 0600, per-machine so a team sync cannot carry it); no OpenAI key is read. `openai/whisper-large-v3-turbo` (ASR), `openai/gpt-audio-mini` (TTS, measured fastest), `google/gemini-3.1-flash-tts-preview` (TTS rescue). **Gotcha**: OpenRouter's audio endpoints live in a namespace absent from the `/models` catalogue, so resolving an audio model against that catalogue falsely reports "no model matched". Optional local `whisper.cpp` and an optional Groq key are supported.

## Dashboard Architecture Constraints

- **Per-vault ApiClient (v0.24.0+)**: `api/client.ts` is a per-vault class and the module-level `api` singleton is retired. Hooks take vault context from VaultContext and instantiate their own client — required by one-window multi-vault.
- **Never reuse a display field as a safety or control predicate (2026-08-11)**: any count or flag driving eviction, mounting or activation gets its own field, named for its purpose. Two runtime defects passed 6,944 green tests. → `knowledge/patterns/presentation-field-must-not-double-as-safety-predicate.md`
