## User Preferences

- Direct decisions on clear choices; explain why. Don't ask permission on obvious paths.
- Rich content in context files. Template placeholders are failure.
- **No em dashes** — use commas/periods/restructure.
- **No implementation details in user-facing copy** (internal rules stay in soul/memory).
- **Brand**: meansoft (company), dreamcontext (product). GitHub org: meanllbrl.
- **UI palette**: Purple-magenta gradient (#641787, #781ca3, #8200a6, #db04b4). Visby CF font. 4px grid.
- **Onboarding: one front door** (`setup`). Half-install states are bugs.
- **Skills enumerate all capabilities**; never say "we don't have X" without checking references first.
- **No page headlines in dashboard** — sidebar nav is the label; page bodies start with content.
- **Dashboard density beats theatricality**: info-dense, searchable, fast. Final report above fold. No gamification.
- **In-app terminal: comfort over sharpness** — JetBrains Mono 14.5px / 1.65, native AA, fuller rendering.
- **Lab = "Insights" in UI** (analytics surface; `lab` CLI is implementation detail).
- **Do not commit unless explicitly asked** (2026-07-25): wait for user direction. Parallel sessions can sweep in-flight work.
- **Turkish content must survive every transform** (2026-07-30): the owner writes task names, tags and directives in Turkish. Slugs fold to ASCII (`foldToAscii`), display uses the frontmatter name verbatim, search/grep is case-insensitive over Turkish. A transform that mangles Turkish is a bug, not cosmetics.

## Communication Style

- Direct, technical. No over-explanation.
- Options: max 2-3, lead with recommendation, one line each.
- Concise progress. Don't narrate steps.
- Flag problems in one line + propose fix. No apologies.

## Project Details

- **Repo**: `~/projects/dreamcontext`, GitHub: `meanllbrl/dreamcontext`
- **Package**: `dreamcontext` (npm), binary: `dreamcontext`

- **Node**: >= 18

## Project Rules

- **ESM everywhere**: `"type": "module"`, `.js` extensions on TS imports, no `require()`.
- **Strict TypeScript**: no implicit any, no unused locals.
- **No default exports for lib**: named only; default only where frameworks require.
- **Register pattern**: commands export `registerXyzCommand(program)`, registered in `src/cli/index.ts`.
- **Commit format**: Conventional commits (feat/fix/refactor/chore/docs/test) + Co-Authored-By.
- **No `.claude/` in this repo**: skill/agents for distribution; install via `dreamcontext install-skill`.
