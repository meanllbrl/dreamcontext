## 2. THE FOCUS GUARD MUST KNOW WHICH CHIP IS ACTIVE (`attention.ts:58-64`, `:92`)
`isWatchingThisWindow()` returns true when the WINDOW is focused, and `raiseAskAttention` uses
it to SKIP the banner and the Dock bounce. With tabs, the window can be focused while the
asking project is a BACKGROUND chip — which is precisely the scenario this feature exists for.
As it stands the user would get nothing.

Do NOT import React state into this module. Inject a predicate:
```ts
export function setChipActiveProbe(probe: ((vault: string) => boolean) | null): void;
```
and change the guard at `:92` to:
```ts
if (isWatchingThisWindow() && (chipActiveProbe?.(key) ?? true)) return;
```
`?? true` is load-bearing: with no probe registered the behaviour is byte-identical to today,
so the launcher window, the browser build and every test keep working unchanged.
