## THE RULE THIS TASK ENFORCES
**Page data stops in the background; the agent surface does not.**

`lib/instanceQueryClient.ts` (Wave 2) already flips a background instance's QueryClient
defaults to `refetchInterval: false` / `refetchOnWindowFocus: false`. That is right for tasks,
knowledge, lab, sleep debt — a hidden project should not poll them.

It is WRONG for the agent surface's own liveness polling. If a background project's
goal-skill run stops being polled, its chip badge FREEZES — and a frozen badge is the exact
opposite of this goal, whose entire point is that a background project can tell you it needs
you. So those queries must override the instance default EXPLICITLY.
