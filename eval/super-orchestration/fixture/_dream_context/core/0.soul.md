## Project Identity

Orbit is a small team-invites product: a mobile app (`orbit-app`) and its HTTP API (`orbit-api`).

## Core Principles

- Small, reviewed changes; every code change in its own branch.
- Conventional commits.

## Constraints

- Node 20, TypeScript strict.
- The API contract in `orbit-api/openapi.yaml` is the source of truth for the app.

## Agent Behaviours & Rules

- Never push; the owner pushes.
